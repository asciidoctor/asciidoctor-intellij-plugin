= JavaFX Preview (removed)
:description: The JavaFX preview is no longer available, use the JCEF preview instead.

{description}

[WARNING]
====
JetBrains removed JavaFX support for plugins from IntelliJ 2025.1.
The JavaFX preview is therefore no longer available from plugin version 0.44.1 onwards.

Install the IDE with the https://www.jetbrains.com/toolbox-app/[JetBrains Toolbox^] and use the xref:features/preview/jcef-preview.adoc[JCEF preview].
See xref:installation.adoc[] for more information.
====
