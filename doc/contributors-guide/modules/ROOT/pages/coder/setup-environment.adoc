= Setup of the development environment
:description: Prepare for developing for the IntelliJ AsciiDoc plugin.
:navtitle: Setup environment

{description}

== Install Mise

Install https://mise.jdx.dev/getting-started.html[Mise] for your operating system by following the installation instructions for your platform.

This project declares its development Java version in `mise.toml`. From the project directory, run `mise install` to install the required version.

== Install the Mise IntelliJ plugin

In IntelliJ, install the Mise plugin from menu:Settings[Plugins]. The plugin lets IntelliJ use the Java version configured by Mise for this project.

== Open and compile the project

Open the project in IntelliJ and import it as a Gradle project. Select the Mise-managed Corretto 25 SDK as the project SDK if IntelliJ prompts you to choose one.

The project is then ready to compile. For command-line builds, run `./gradlew buildPlugin` on Linux/macOS or `gradlew.bat buildPlugin` on Windows.
